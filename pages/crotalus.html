Project Overview

crotalus is a real-time supply-chain malware scanner for PyPI. It watches the package index for new releases, pulls each sdist and wheel, and decides whether the code inside is malicious — typically within about 22 seconds of upload. The goal is to catch typosquats, malicious install hooks, and hijacked legitimate libraries before anyone pip installs them.

The pipeline handles roughly 6,000 releases a day, with horizontally scalable workers pulling from a PostgreSQL job queue. On a benchmark of 495 known-malicious packages it flags 89% of them, while correctly leaving 974 of 996 popular, benign packages alone.

    How It Works

    • Ingest: New releases are picked up from PyPI and queued in PostgreSQL; workers claim jobs and can be scaled out independently.
    • Static analysis: Archives are parsed in memory and 11 detection rules run over the Python AST — looking for malicious setup.py install hooks, .pth startup persistence, obfuscated payloads, and suspicious network/exec behavior.
    • Typosquat detection: Package names are compared against popular packages to catch near-miss impersonations.
    • LLM triage: Borderline releases are sent to Gemini for a second look, with prompt-injection hardening since the input is untrusted attacker-controlled code. This step raised detection from 83% to 89% with no added false positives.
    • Serving: A Go REST API exposes verdicts, deployed in Docker on AWS EC2.

    Languages and Tools Used

    • Languages: Python, Go, SQL
    • Data: PostgreSQL (also used as the job queue)
    • Infrastructure: Docker, AWS EC2
    • LLM: Gemini API for near-miss triage
