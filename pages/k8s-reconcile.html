Project Overview

k8s-reconcile is an LLM agent that diagnoses and repairs broken Kubernetes deployments, plus a benchmark that measures how well different models do it and what it costs. The agent gets one namespace with something wrong in it, investigates with a few read-only tools, and explains the root cause. With writes enabled, it also patches the broken Deployment and checks that the rollout recovered.

Across 160 graded runs, Claude Opus passed all 40 repairs. Claude Haiku passed 37 of 40 at about 1/25 of the cost per passing repair, and every Haiku miss was on the hardest tier, where the cause sits in the healthy-looking side of a client–server pair.

  • Repair beats diagnosis. A diagnosis only has to sound right; a repair has to survive the rollout check, which turns a wrong idea into a failure the model can read and correct. Haiku goes from 55% diagnosing to 93% repairing.
  • Cost. $0.0014 per passing Haiku repair versus $0.0343 for Opus. All 160 agent runs cost $2.24.
  • Caching. Caching the tool and system-prompt prefix plus the conversation history cut agent cost by 53%.

How It Works

  • One namespace: every tool is bound to a single namespace when the toolbox is built, so the model can't reach anything else. It sees Deployments, Pods, events, and logs, but not Services, ConfigMaps, or Secrets, and it has no shell.
  • Compact tools: get_pods, get_events, get_deployments, and get_logs return short text summaries instead of raw JSON, so each result costs hundreds of tokens rather than thousands.
  • Guarded writes: apply_patch is off by default. Patches are size-limited, restricted to spec.template, dry-run on the server, and audit-logged.
  • Rollout check: after a patch, the agent watches the new pods and gets back a verdict. That is what lets it catch and undo a wrong fix.
  • Benchmark and judge: each tier recreates its fault from a manifest, runs the agent, and records every step. An LLM judge grades the transcript against an answer key listing the faults, the correct fixes, and the tempting wrong ones.
